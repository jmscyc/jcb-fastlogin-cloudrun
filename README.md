# JCB 悠遊卡極速自動搶登錄系統 (Hugging Face Edition)

專為每月 JCB 晶緻卡/極緻卡悠遊卡自動加值 10% 現金回饋活動打造的雲端自動化控制台。
內建 Playwright Chromium 核心、防檢測指紋 (Stealth)、多卡並行、預約定時排程與 Telegram / Webhook 即時通知。

## 特色
- ☁️ 部署於 Hugging Face Spaces (2 vCPU, 16GB RAM)
- 💳 支援卡片庫加密儲存與批次匯出/匯入
- ⚡ 毫秒級搶登探測與異常自動重試
